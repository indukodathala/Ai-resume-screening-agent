# 🤖 AI Resume Screening Agent

An AI-powered Resume Screening Agent that automatically analyzes candidate resumes against job requirements and helps recruiters identify suitable candidates.

## 🚀 Features

- 📄 Supports PDF and DOCX resumes
- 🤖 AI-powered resume analysis
- 📊 Match score generation
- ✅ Required skills matching
- ⭐ Preferred skills matching
- 💪 Candidate strengths
- ⚠️ Candidate weaknesses
- 📝 Candidate summary
- 🎯 Shortlist/Reject decision
- 👥 Multiple-resume screening
- 🏆 Candidate ranking
- 🌐 Streamlit web interface

## 🛠️ Technologies Used

- Python
- OpenAI API
- Streamlit
- PyMuPDF
- python-docx
- python-dotenv
- Git & GitHub
